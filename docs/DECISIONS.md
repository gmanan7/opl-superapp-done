# Fulcrum — Decision Log

**Status:** Append-only. Every meaningful architectural, product, or security decision gets a row here: what was decided, when, why, and what it rules out. This is the document that stops the project from re-litigating settled questions and stops any build session (human or Claude Code) from quietly contradicting an earlier choice.

**Rules:**
- Never delete or rewrite an entry. If a decision is reversed, add a NEW entry that supersedes it and link both.
- Claude Code: before contradicting anything in this file, stop and ask. To change a decision, propose a new entry first.
- Keep entries short. Detail lives in the linked docs.
